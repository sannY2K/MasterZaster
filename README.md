# MasterZaster

Plugin VST3 para Windows y Ableton Live: ingeniero de mezcla virtual con análisis de
referencias, diagnóstico de mezcla y sugerencias de EQ. Funciona sin conexión.

**Estado:** V1, hito M0 (esqueleto). El plugin compila y deja pasar el audio con una
ganancia de salida; todavía no tiene análisis ni referencias.

- `docs/MASTERZASTER_SPEC.md`: especificación completa
- `docs/V1_PLAN.md`: viabilidad, arquitectura y plan de V1
- `docs/BUILD.md`: cómo compilar e instalar
- `docs/TEST_CHECKLIST.md`: pruebas manuales
- `docs/HANDOFF.md`: prompt para continuar el desarrollo en una sesión nueva
